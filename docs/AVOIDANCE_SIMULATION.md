# AI 모델 기반 청정지수·회피강도 시뮬레이션 (2026-11-16)

## 목적과 중요한 한계

- 경로 A* 기존 비용: `링크 길이(m) × [1 + 회피강도 가중치 × (모델 보정 위험점수 / 100)]`
- `청정지수=100-모델 보정 위험점수`. 이것은 **담배 연기 농도·사용자의 냄새 인지 확률이 아님**.
- 기준의 “최적”은 모델 위험 비용 감소량과 추가 보행 거리 사이 선택을 뜻하며, 실제 건강 효과의 최적성은 아님.
- **실제 강남구 보행 GraphML 및 학습 결과 CSV를 이 개발 실행에서 통합 검증한 것은 아님**. 아래 1차 수치는 가상 시나리오의 결과.

## 가상 시나리오 1차 실험

- 24×24 격자형 보행망 (576개 노드, 인접 셀 간 동일 거리)
- 5가지 위험 분포(위험원 4, 8, 12, 18, 30개), 고정된 난수 시드 20261116
- 각 위험 분포에서 200개의 무작위 출발·도착 쌍, 총 1000조건
- 거리별 위험 점수 감쇠: 가상 격자 스케일 기준 0~3칸 100%, 3~5칸 65%, 5~7칸 30% (실제 10/15/21m가 아님)
- 각 경우 동일한 그래프에서 최단거리 기준 및 가중치 후보 (0, .25, .5, 1, 1.5, 2, 3, 4, 6, 8, 10) 비교
- 위험 비용 정의: 링크를 따라 `길이 × 모의 정규화 위험` 합산
- 가상 격자에는 동등 최단거리 우회로가 많아 회피 이득이 부풀려질 가능성이 큼

| 가중치 | 평균 추가 거리 | 평균 모의 위험비용 감소 | 우회율 상위 10% 값 |
|---:|---:|---:|---:|
| 0.5 | 0.00% | 22.87% | 0.00% |
| 2.0 | 0.88% | 24.00% | 0.00% |
| 3.0 | 2.35% | 25.48% | 7.41% |
| 4.0 | 3.51% | 26.19% | 10.53% |
| 6.0 | 5.78% | 27.27% | 20.00% |
| 8.0 | 7.34% | 27.77% | 27.27% |
| 10.0 | 8.76% | 28.14% | 33.33% |

감소율은 위험이 0인 일부 기준 경로를 제외한 비교값이며, 실측 흡연 노출 감소율을 말하지 않습니다.

**임시 운영 권고**: 실제 보행망 결과가 나오기 전까지 `low=.5 / medium=2 / high=6`을 **변경하지 않습니다**. 가중치 6→10에서 평균 우회는 약 3.0%p 늘고 모의 위험 비용 감소는 약 0.9%p 증가하는 정도입니다. 이 값 역시 현실 지도에서 검증되지 않았습니다.

## 사용자에게 보여줄 '체감 수준' 문구

실제 연기가 얼마나 느껴지는지에 대한 표현은 임의로 보장할 수 없으므로 **예상 경로 선택 성향**을 설명합니다.

- **낮음 — 가까운 길 우선:** 이동거리를 우선하며 비슷한 거리의 길 중 모델 위험점수가 낮은 쪽 선호
- **보통 — 거리와 회피의 균형:** 조금 돌아가도 모델 위험점수가 낮은 경로를 선택할 수 있음
- **높음 — 회피 우선:** 위험점수가 낮은 길을 적극 선택해 우회 거리 증가 가능

※ 바람·보행 환경·흡연 시점·개인별 민감도를 고려하지 않으므로 담배 냄새 인지, 연기 노출량, 증상 정도를 예측하는 문구가 아닙니다.

## 청정지수 분류 기준 제안

1. 시각화 및 API 값 자체는 기존의 **0~100 연속 점수로 유지**합니다.
2. ‘상대적으로 낮음/높음’ 등의 **지도 범례 컷오프는 길이가중 분위수**를 우선 실험합니다. `clean_p20, clean_p40, clean_p60, clean_p80`를 계산해 5단계 후보로 사용합니다.
3. 해당 분위수는 **모델 위험점수가 매핑된 링크**에서만 산정합니다. 점수가 없는 길을 청정 100으로 간주하지 않습니다.
4. 실제 CSV의 값이 한 수준에 몰리면 동일한 컷오프가 발생할 수 있습니다. 이때는 단계 수를 줄이거나 절대점수 기준을 유지하고 지표를 다시 검토합니다.
5. 모델 보정 점수의 상대 위험 순위가 지역이나 학습 데이터가 바뀌면 달라질 수 있으므로 단계명은 건강 안전 판정이 아닙니다.

## 실제 데이터 반복 실험 실행

GraphML `data/processed/walking_network/gangnam_walk.graphml`과 학습 결과 CSV가 로컬에 있어야 합니다. 브랜치의 환경 의존성을 설치한 터미널에서:

```powershell
$repo = (git rev-parse --show-toplevel).Trim()
$env:LUNG_RISK_CSV = Join-Path $repo "notebooks/03_modeling/결과/전처리기반/1_위험지도_지점.csv"
Test-Path $env:LUNG_RISK_CSV
python app/backend/simulate_avoidance.py --pairs 80 --seed 20261116 --output avoidance_results.csv
```

출력: 가중치별 평균 우회율, 90백분위 우회율, 모델 위험비용 감소율, 20% 초과 우회 경로 비중과 실제 청정지수 분위수. 
`--pairs 200`처럼 반복횟수를 늘려 결과 안정성을 확인하십시오. 현재 실제 망 시뮬레이션은 **원본 그래프의 노드 간 경로 기준**이고, 실제 앱의 좌표 스냅·가상 연결 링크는 포함하지 않습니다. 실제 서비스 최종 검증 시 앱 API를 사용하는 별도 End-to-End 경로 검증이 필요합니다.

## 추후 최적값 변경 판단 기준 (제안)

같은 표본 출발/도착·동일한 모델 데이터에서 최소 3개 시드로 재검증합니다.
- 낮음: 평균 우회율 0~3% 목표
- 보통: 평균 우회율 3~8% 목표
- 높음: 평균 우회율 8~15% 목표, 90백분위 우회율 과도한 증가 확인
- 각 강도의 평균 위험비용 감소 / 추가 우회 거리의 한계효과와 이용자 선호 조사를 함께 비교

수치는 **가이드 목표일 뿐 의료 기준이나 현재 달성된 효과가 아닙니다.** 목표 구간에 들어오는 가중치가 없으면 임의로 채우지 않고 결과에 따라 강도 구분을 재설계해야 합니다.
