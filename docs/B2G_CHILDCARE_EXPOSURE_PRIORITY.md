# B2G 어린이집 보호 우선순위

지자체 관리자 로그인 후 **지자체 분석 → 어린이집 보호 우선순위** 탭에서 강남구 어린이집의 주변 AI 위험지수 기반 보호 우선순위를 확인합니다.

## 데이터 출처

- 생성 코드: `notebooks/03_modeling/2_서비스/3_B2G_비흡연자_아동간접흡연보호리포트.py`
- 기본 입력 CSV: `notebooks/03_modeling/결과/3_어린이집_노출순위.csv`
- 대체 경로: `LUNG_CHILDCARE_EXPOSURE_CSV` 환경 변수에 **CSV 전체 경로** 지정
- 관리자가 탭을 열면 `GET /api/b2g/childcare/exposure`를 HTTP Basic 인증으로 호출합니다. 백엔드가 CSV를 읽어 응답하며, 요청 중 모델을 다시 학습하거나 순위를 생성하지 않습니다.
- CSV가 없거나 필수 컬럼/숫자/좌표가 올바르지 않으면 503 오류와 원인을 표시합니다. 가상 데이터를 사용하지 않습니다.

예시(Windows PowerShell, FastAPI를 실행하는 동일 터미널):

```powershell
$env:LUNG_CHILDCARE_EXPOSURE_CSV = "D:\\data\\3_어린이집_노출순위.csv"
```

## 데이터 필드 및 계산

CSV 필요 컬럼: `어린이집명`, `유형`, `주소`, `현원`, `위도`, `경도`, `주변지점수`, `주변_최고위험점수`, `주변_평균위험점수`, `주변_상위10%지점수`, `노출점수`, `우선순위`.

원래 분석 코드의 기준:

- **100m 반경** 내 보행 분석 지점의 모델 상대 위험점수 사용
- **노출점수** = (최고 위험점수 × 0.5) + (평균 위험점수 × 0.5)
- **우선순위** = 노출점수 내림차순(`rank(method="min")`), 동점이면 동일 순위; 동점은 현원 기준으로 정렬
- 주변 지점이 없다면 원본 CSV에 노출점수 0이 들어가지만 실제 안전 판정은 아니므로 화면에서는 **지점 없음**으로 표시

## 화면

- 관리자 전용 탭 (기존 DBSCAN 입지 추천 옆)
- 어린이집 이름/주소 검색, 상위 10% 위험지점 인접 시설 필터
- 우선순위, 노출점수, 현원, 주변 지점 수, 주변 최고/평균 위험점수, 상위 10% 위험지점 수
- 지도에서 위치 확인 시 보라색 어린이집 마커와 위치 이동
- **주의:** 현재 흡연 여부, 측정된 대기질, 개별 아동의 실제 간접흡연 노출을 의미하지 않음

## 범위와 주의사항

이 탭에서는 기존 분석 CSV의 순위를 그대로 보여줍니다. 어린이집 데이터를 재학습하거나 위험도를 실시간 재계산하지 않습니다. B2C 경로 탐색과 기존 B2G DBSCAN API는 변경하지 않습니다. 실제 CSV 내용과 브라우저 결과는 데이터를 준비한 환경에서 별도 테스트가 필요합니다.
