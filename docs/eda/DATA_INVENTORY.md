## 아직 필요한 조치
1. **도보 네트워크 CSV**와 **상권정보 ZIP**을 Google Drive 공동 폴더에서 공유하고, 파일명·크기·체크섬을 기록한다. 두 대용량 파일을 Git에 강제 추가하지 않는다.
2. 서울 전체 250m 격자 기준과 CRS, 공통 grid_id 규칙 및 좌표계 변환 기준을 팀 합의로 확정한다.
3. 흡연시설·금연구역·생활인구가 실제 흡연 발생 정답 라벨은 아님을 명확히 한다. 예측 모델은 실제 관측·제보·민원 등 검증 가능한 라벨의 공간/시간 커버리지를 점검한다.
4. 현재 저장소의 일부 데이터는 .gitignore 설정 전 Git에 추적된 상태다. 새 대용량 데이터의 추적은 피하고 기존 파일 제거/이력 정리는 별도 합의 후 진행한다.
5. Drive 업로드 여부는 GitHub 연결만으로 확인할 수 없으므로 팀 공유 Drive에서 별도 확인한다.
