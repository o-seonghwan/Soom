1. 전처리 전 전체 행·열, 자료형, 식별자, 기간·공간 범위, 컬럼 사전
2. 결측·중복·이상치·범주값·좌표계·지리적 오류 분석
3. 데이터 특성에 맞는 기초 통계와 시각화 (해석 Markdown 포함)
4. 정제 전후 행 수, 컬럼, 변환 규칙, 제외 기준
5. data/processed/[데이터셋명]_clean.csv와 _summary.csv 생성 및 재읽기 검증
6. 근거가 있는 경우에 한해 _features.csv 생성. 변수명·계산식·공간/시간 단위 설명
7. 250m 격자 결합 가능성, 머신러닝 입력/목표 변수, 지도학습 라벨 존재 여부 검증
8. 흡연 위험요인 분석, 시간대별 분석, 경로 가중치, 지도 서비스 중 실제 가능한 활용 방법 설명
9. 부족한 데이터, 가정, 통계적 한계, 다른 데이터 결합을 위해 필요한 컬럼
10. Notebook 전체 재실행 가능하도록 구성하고, 결론에 사용/추가정제/추가데이터필요/보류 판정

산출물은 notebooks/01_eda/EDA_[데이터셋명].ipynb와 로컬 CSV들이다. 데이터셋별 Git 브랜치를 사용하고 PR에는 Notebook과 분석 요약만 추가한다. .gitignore에 걸리는 대용량 CSV를 강제 커밋하지 않는다.

**주의**: 원본 수정 금지. 근거 없는 흡연 발생 라벨 생성 금지. 실제 예측 성능을 검증 없이 주장하지 않는다. 데이터 로딩 불가 등 제약 시 그 원인과 재현 방법을 명시한다.
